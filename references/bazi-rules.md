## 一、十神含义

以日干为「我」，其余干支与我的生克关系定十神。

| 十神 | 关系 | 核心象义 | 正面 | 负面 |
|------|------|---------|------|------|
| 比肩 | 同我·同阴阳 | 自我、同辈、竞争 | 独立自主、意志坚定 | 固执、不服管、破财 |
| 劫财 | 同我·异阴阳 | 合作、耗财、争夺 | 讲义气、善交际 | 冲动、易被拖累 |
| 食神 | 我生·同阴阳 | 才华、口福、温和输出 | 聪明、有涵养、福气 | 懒散、想多做少 |
| 伤官 | 我生·异阴阳 | 才艺、叛逆、表达 | 才华横溢、有创意 | 傲气、犯上、克官 |
| 偏财 | 我克·同阴阳 | 意外之财、交际、父 | 慷慨、善经营、机遇多 | 挥霍、投机 |
| 正财 | 我克·异阴阳 | 稳定收入、妻、务实 | 勤俭、务实、守信 | 吝啬、保守 |
| 七杀 | 克我·同阴阳 | 压力、魄力、权柄 | 果断、能扛事、有威 | 急躁、多灾、被制 |
| 正官 | 克我·异阴阳 | 责任、名分、夫/官 | 自律、守规矩、贵气 | 拘谨、受约束 |
| 偏印 | 生我·同阴阳 | 偏门智慧、玄学、继母 | 悟性高、专业深 | 孤僻、多疑 |
| 正印 | 生我·异阴阳 | 学识、母亲、庇荫 | 仁慈、有靠山、利学业 | 依赖、懒于行动 |

**组合要诀**
- 官印相生：贵气、有担当，宜公职/管理。
- 食神制杀：以才华化解压力，能成大事。
- 伤官配印：才华配学养，文名之象。
- 财官双美：富贵格局。
- 比劫夺财：合伙易破财，宜独立经营。

## 二、五行与调候

- **五行相生**：木→火→土→金→水→木
- **五行相克**：木克土、土克水、水克火、火克金、金克木
- **日主强弱**：同党（比劫 + 印）占比越高越强。≥62% 身强，45%–55% 中和，≤38% 身弱。
- **喜用神**：
  - 身强 → 喜「克泄耗」：官杀（克）、食伤（泄）、财（耗）。
  - 身弱 → 喜「生扶」：印（生）、比劫（扶）。
- **调候用神**（《穷通宝典》核心）：不同日干生于不同月令，有特定调候之物。
  - 甲木生酉月（秋）→ 先用丁火制金，次用丙火。
  - 丙火生冬月 → 必用甲木、壬水，木火通明。
  - 庚金生夏月 → 须壬水淘洗、戊土生金。
  - 具体调候请结合月令寒暖燥湿判断，不可机械套用。

## 三、格局（《子平真诠》）

**取格**：以月令本气十神为格；月令本气不透则取中气、余气；透干者格局更清。

| 格局 | 成格条件 | 破格 |
|------|---------|------|
| 正官格 | 官星透干、有财生印护 | 伤官见官、官星被合 |
| 七杀格 | 有食制或印化 | 杀无制化、身弱杀旺 |
| 正财格 | 财旺身强、有官护财 | 财多身弱、比劫夺财 |
| 偏财格 | 财星得地、身能任财 | 财星被劫 |
| 正印格 | 印旺身强、有官生印 | 财破印 |
| 食神格 | 食神吐秀、身强食旺 | 枭神夺食 |
| 伤官格 | 伤官配印或伤官生财 | 伤官见官无制 |
| 建禄/月劫 | 禄劫得用、有官杀制 | 无制无化、比劫成群 |

**格局高低**：看用神是否有力、是否受制；格局清纯有力则高，混浊受制则低。

## 五、大运与流年

- **顺逆**：阳年男 / 阴年女顺排；阴年男 / 阳年女逆排。
- **起运**：出生到最近「节」的天数 ÷ 3 = 年（余 1 天≈4 月）。
- **大运**：每步 10 年，从月柱的下一柱（顺）或上一柱（逆）起，**不含月柱本身**。
- **流年**：以当年干支与原局、大运论生克。
- **论法**：
  1. 大运定十年基调（大运干支对日主的喜忌）。
  2. 流年定当年吉凶（流年与原局/大运的刑冲合会）。
  3. 大运流年同气（如均助喜用）则吉应显著；互相冲克则多变动。
  4. 岁运并临（大运流年同干支）、天克地冲，主大变动之年。

## 六、经典典籍要点

- **《滴天髓》**：论气势格局，重「中和」与「流通」；「能知衰旺之真机，其于三命之奥，思过半矣」。
- **《子平真诠》**：论格局用神，以月令取格，重「用神之成败」。
- **《穷通宝典》**：论调候，按月令寒暖燥湿定喜用，最实用。
- **《三命通会》**：百科全书式，神煞、纳音、格局兼备。
- **《渊海子平》**：子平法源头，十神六亲体系。

**引用规范**：论断时注明出处，如「依《穷通宝典》调候，庚金生巳月，火旺金柔，须壬水淘洗、戊土生金」。

## 七、解读纪律

1. 先看日主强弱与调候，定喜忌基调。
2. 再论格局成败，判格局高低。
3. 结合十神论六亲、事业、财、婚。
4. 以神煞作细节补充，不作主断。
5. 大运流年落到具体年份与人生阶段。
6. **忌**：绝对化断语、恐吓性表达、替代医疗与投资决策。
